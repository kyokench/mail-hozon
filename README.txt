メール文章ライブラリ IndexedDB版

ブラウザタブには、メール保存を表す専用ファビコンが表示されます。

■ 今回の変更
メールごとに複数の添付ファイルを保存できるようにしました。
編集画面で追加・取り外し、閲覧画面でダウンロードできます。
添付ファイルもJSONバックアップ / 復元の対象です。
（1ファイル25MB、1メール合計50MBまで）

■ メリット
・localStorageの約5MB制限を気にしにくい
・数千件以上のメール文章も扱いやすい
・将来的に大量データや追加項目へ拡張しやすい

■ 既存機能
・メール文章の保存 / 編集 / 削除
・自由なフォルダ
・ドラッグ＆ドロップによるフォルダの表示順変更
・ドラッグ＆ドロップ
・お気に入り
・タグ
・全文検索
・サイボウズ Office出力TXTの一括取込（選択 / ドラッグ＆ドロップ）
  Subject、Date、From、To、Cc、本文を自動解析します。
・日時修正
・複数ファイルの添付 / ダウンロード
・編集画面への添付ファイルのドラッグ＆ドロップ
・一覧画面の添付ファイルリンクから直接ダウンロード
・カード表示 / 本文抜粋付き1行文字表示の切り替え（選択を記憶）
・一覧の「抜粋文」メニューで表示 / 非表示を切り替え（選択を記憶）。非表示時は文字表示の件名欄が広がります。
・「文字サイズ」メニューで最小 / 小さめ / 標準 / 大きめ / 最大の5段階に切り替え（選択を記憶）。以前の「小さめ」設定も引き継ぎます。
・カードクリックで大きく表示
・閲覧画面の最大化
・閲覧画面上部のコピー / 編集 / 削除操作
・本文のスクロール末尾に添付ファイルを表示
・サイボウズ取込メールのFrom / To / Ccを必要時だけ展開表示
・JSONバックアップ / 復元
・選択中フォルダだけのバックアップ / 既存データへ統合して復元

■ localStorage版からの移行
同じオリジンで以前のlocalStorage版を使っている場合、
IndexedDBが空なら初回起動時に自動移行を試みます。

ただし、index.htmlを直接開く file:// 環境では、
ブラウザや開き方によって保存領域の扱いが変わる場合があります。

そのため、旧版ですでに重要なデータがある場合は、
念のため旧版からJSONバックアップを作成しておくことをおすすめします。

■ 使い方
index.html をEdgeやChromeで開けば動作します。

より安定して使うなら、ローカルWebサーバーや
自分のWebサーバー上に配置して http:// または https:// で開く方法がおすすめです。
